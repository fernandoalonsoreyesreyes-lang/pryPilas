# EjemploPila1 — Pilas en Java

## 📋 Descripción

Proyecto en **Java** para ejemplificar el uso de **Pilas (Stacks)**.

El programa crea una pila de **10 elementos** que almacena nombres de personas
y permite realizar las operaciones básicas de una pila: **insertar (push)**,
**extraer (pop)** y **mostrar** los elementos.

Este proyecto corresponde a la unidad de **Pilas y Colas** de la materia
de Estructura de Datos.

## 🎯 Objetivo

Aplicar la estructura de datos **Pila (LIFO - Last In, First Out)**,
donde el último elemento que entra es el primero que sale.

## ⚙️ Funcionalidades

El programa muestra un menú con las siguientes opciones:

1. **Poner elemento en la Pila** — Inserta un nombre en la pila.
2. **Quitar elemento de la pila** — Extrae y muestra el último nombre insertado.
3. **Mostrar elementos de la pila** — Muestra todos los nombres que hay en la pila.
4. **Salir** — Termina el programa.

## 🛠️ Tecnologías utilizadas

- **Lenguaje:** Java
- **JDK:** 17 o superior
- **IDE:** NetBeans
- **Paradigma:** Programación Orientada a Objetos (POO)
- **Estructura de datos:** Pila

## ▶️ Cómo ejecutar el proyecto
- **Opción 1: Desde NetBeans**
- Clona el repositorio.
- **En NetBeans:** File > Open Project y selecciona la carpeta EjemploPila1.
- **Ejecuta la clase** EjemploPila1.java con F6 o Run.

- **Opción 2: Desde la terminal**
- **1. Clonar el repositorio**
git clone https://github.com/fernandoalonsoreyesreyes-lang/EjemploPila1.git

- **2. Entrar a la carpeta src**
cd EjemploPila1/src

- **3. Compilar**
javac ejemplopila1/*.java

- **4. Ejecutar**
java ejemplopila1.EjemploPila1
